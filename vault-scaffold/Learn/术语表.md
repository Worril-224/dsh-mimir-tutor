# 术语表

这个库的词汇：只收课程**实际用到、并且为了往下走不得不定义**的冷门词。普通读者本来就拥有的词（干旱、养分、森林、岩石）永远不立条目。

每个词一条笔记，放在 `Learn/Glossary/`：

- 定义（一两句，第一次出现处带行内维基百科链接）
- 它为什么在这里（来自哪次会话、哪条线索）
- 教过（0–3，讲授实际触及了多少）
